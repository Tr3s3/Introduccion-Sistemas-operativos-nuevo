# OCR de exámenes

Esta carpeta contiene textos extraídos automáticamente con `scripts/extract_scanned_content.py` (PyMuPDF + RapidOCR) a partir de PDFs escaneados y fotos/JPEG de exámenes/modelos.

## Importante

- Los archivos son **salida de OCR**: pueden contener errores en símbolos, fórmulas, números, tablas o manuscrito.
- Ante cualquier duda, contrastar con el archivo original.
- Se usan como apoyo para integrar preguntas/ejercicios en `06`, `07`, `08`, `09` y `10`.
