# 2.6.2 Sincronización y condiciones de carrera

> [!abstract] En una frase
> Cuando varios procesos o hilos usan el mismo dato sin control, el resultado depende del orden de ejecución: es una **condición de carrera**. La **sincronización** (regiones críticas, semáforos, mutex, monitores) la evita.

## Desarrollo
### Condición de carrera
Ocurre cuando dos o más procesos/hilos acceden a datos compartidos y el resultado depende del orden de ejecución.

**Ejemplo:** `x = 5`; P1 hace `x = x + 1`; P2 hace `x = x + 1`. El resultado correcto es 7, pero si ambos leen `5` antes de que el otro escriba, ambos escriben `6`.

### Región crítica
Fragmento de código que accede al recurso compartido. Debe ejecutarse con **exclusión mutua**.

**Condiciones para una buena solución** (Tanenbaum):
1. **Exclusión mutua:** dos procesos no pueden estar simultáneamente en su región crítica.
2. **Progreso:** si nadie está en la región crítica, la decisión de quién entra no se posterga indefinidamente.
3. **Espera acotada:** ningún proceso espera para siempre para entrar.

### Mecanismos
| Mecanismo | Idea | Observación |
|---|---|---|
| **Mutex/lock** | Solo un proceso entra; el otro espera | Simple; cuidado con deadlock |
| **Semáforo** | Contador entero con `wait/down/P` y `signal/up/V` | Binario (=mutex) o contador |
| **Monitor** | Abstracción de alto nivel con exclusión mutua implícita | Más seguro; lo gestiona el lenguaje/entorno |
| **Software** | Peterson, Dekker | Didácticos; limitados en multiprocesador moderno |
| **Hardware** | TSL/XCHG, deshabilitar interrupciones | Base para primitivas del SO |

**Ejemplo clásico:** productor–consumidor con buffer acotado (semáforos `empty`, `full` y `mutex`).

> [!warning] Riesgos
> **Deadlock/interbloqueo:** espera circular por recursos. **Starvation:** un proceso nunca obtiene el recurso. **Busy waiting:** gastar CPU esperando; preferible bloquear cuando sea posible.

## Cómo responderlo en el final
Definir la carrera con un ejemplo de dos procesos que incrementan la misma variable, y luego nombrar región crítica y semáforo/mutex.
